# Placeholder assets: personal use only

Everything in this folder is a **placeholder**.

- `textures/` (except `chest.png`), `fonts/` and `sounds/` were taken from the
  reference app (shantiashams/book-and-quill), which ships Minecraft assets.
  They belong to Mojang/Microsoft and are used here for personal use only.
- `textures/chest.png` is our own pixel art, generated by
  `scripts/generate_placeholder_art.py`.

**Replace every Mojang-derived file with redrawn textures, an original font and
original sounds before sharing or distributing the app.**

To swap assets, replace files in this folder keeping the same file names (the
names are listed in `Sources/BookAssets/AssetCatalog.swift`). Textures are
pixel art drawn at 1 texel = 1 GUI pixel and are scaled with nearest-neighbour.
