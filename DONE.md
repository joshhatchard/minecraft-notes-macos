# Done: Book and Quill Notes v1

## What was built
A native macOS 26 SwiftUI app, split into a Swift package of modules (see `docs/ARCHITECTURE.md`):

- **Home: chests (semesters).** Create, rename and delete chests (delete asks first). Each chest is drawn as our own pixel-art chest.
- **Chest: shelves (subjects).** Each shelf is a row of chiseled-bookshelf blocks with 6 slots each, growing as books are added.
  - Click an empty slot to write a new book there. Click a book to open it.
  - Drag a book onto any slot to move it; dropping on an occupied slot swaps the two books.
  - Drag a shelf's name plate onto a chest in the sidebar to move the shelf to that chest.
  - Context menus for create, rename and delete (all deletes ask first).
- **Book editor.** Laid out with Minecraft's book-screen coordinates, scaled by the largest integer factor that fits the window:
  - "Page X of Y", 14 lines, 256 characters and 100 pages, enforced while typing and pasting, including word wrap.
  - page_forward/backward arrows that highlight on hover. The forward arrow on the last page adds a page.
  - Flip animation and the page_turn sound on every turn.
  - Sign opens the "Enter Book Title" screen (title, author, and the "no longer editable" warning) with Sign and Close or Cancel. Signed books are read-only.
- **Sounds.** Page turn (three random variants), button click, chest open (insert.wav), book open (pickup.wav), book placed (insert.wav). No music.
- **Storage.** Plain files under `~/Documents/Book and Quill` (changeable in Settings):
  - Layout: `<Chest>/<Shelf>/<Book>.book/{book.json, pages/001.md…}`, with `library.json` and `chest.json` for ordering.
  - Writes are atomic: temp file, then fsync, then rename.
  - Autosave runs after 600 ms of no typing, and also on Done/back, when the app loses focus, and on quit.
  - Moves are real folder moves.
  - Name collisions get a number added ("Maths 2"). Illegal filename characters are replaced.
  - A corrupted book.json is recovered and kept as a backup. Deletes go to the Trash.
- **Assets.** Everything sits behind `AssetCatalog` in one folder, `Sources/BookAssets/Assets`. Its README says the files are placeholders for personal use only. The chest texture and app icon are our own art, generated by `scripts/generate_placeholder_art.py`.

## How to run
```
make app && open build/BookAndQuill.app
make test        # unit tests
make run         # run without bundling
make lint        # swift-format
```

## Results (verified in this session)
- `make build` / `swift build`: success, no warnings from our sources.
- `make test`: **98 tests passed, 0 failed.**
  - BookCore 40: wrapping, the 14-line and 256-character limits, unicode, newlines, paste clipping, the book model, signing lock, names, shelf slots.
  - BookStorage 28: a shared contract suite run against both the file-system repository and the in-memory one, plus file-system tests for the folder layout, atomic writes, corrupted JSON, collisions, illegal characters, slot repair and page files.
  - BookUI 30: navigation, autosave/flush, add page and the 100-page cap, signing, drag-move of books and shelves, and the asset bundle. One test checks that AppKit wraps page text into exactly the line count the core rules compute (12 samples × scales 1 to 3).
- `make lint`: clean.
- `make app`: build/BookAndQuill.app is assembled, ad-hoc signed and passes `codesign --verify --strict`. Opened with `open`, the process was running (`pgrep`), then quit with `pkill`.
- **Screenshot: not possible.** `screencapture` fails with "could not create image from display" because this session has no screen-recording permission. The UI has **not been checked by eye**.

## Known gaps
- Not yet tried in a real window: layout and spacing, drag and drop, the flip animation and sound playback.
- Plain `swift test` inside this iCloud-synced Desktop folder fails to codesign the test bundles because iCloud adds file attributes. Use `make test`, which builds in `~/Library/Caches/BookAndQuill-build`, or move the repo out of the synced folder.
- The pixel font only covers ASCII. Other characters render in a system fallback font; they are measured correctly but don't look pixel-art.
- Book titles show as hover tooltips and in a shelf caption, not drawn on the book spines.
- No way to reorder chests or shelves by drag (only move shelves between chests), and no page deletion. Neither was in the brief.
- Staged assets the app doesn't use stay in `_staged_assets/` (gitignored), e.g. cobblestone, the grid font, page_turn.wav.
- Placeholder Mojang assets must be replaced before sharing.
